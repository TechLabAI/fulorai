# MIG-008 -- Observability: run logs + actuator health/readiness

## Contexto
Execuções de migração precisam ser observáveis e a prontidão (readiness) reportável,
para que orquestradores/probes saibam quando os serviços de negócio podem iniciar.

## Spec de referencia
- SPEC-07 (Observability & health)

## Escopo
- Logging estruturado SLF4J (`@Slf4j`) com `runId` via MDC.
- Log de início/fim: schemas-alvo, aplicadas, pendentes, duração.
- Log de falha em ERROR com versão/arquivo/schema.
- Actuator `health` (liveness/readiness), `info`, `flyway`; readiness `UP` só após sucesso.

## Resultado esperado
Cada execução é rastreável por logs e o estado é exposto via actuator.

## Criterios de aceite
- [ ] Início da execução loga schemas-alvo e `runId`.
- [ ] Cada migração aplicada loga versão/arquivo/schema.
- [ ] Falha loga em ERROR e resulta em exit não-zero.
- [ ] `/actuator/health` readiness `UP` apenas após execução bem-sucedida.
- [ ] Nenhum uso de `System.out`.
