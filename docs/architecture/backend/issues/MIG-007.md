# MIG-007 -- Security: env credentials + migration role + clean disabled

## Contexto
MIG detém privilégios DDL elevados sobre todo o banco. As credenciais devem vir do
ambiente e o papel de migração deve ser distinto do papel de runtime dos serviços.

## Spec de referencia
- SPEC-06 (Security)
- ADR-005

## Escopo
- Credenciais via `${VAR_NAME}` (`MIG_DB_URL/USER/PASSWORD`), sem defaults commitados.
- Fail-fast se variável obrigatória ausente.
- `cleanDisabled=true` mantido em todos os ambientes.
- Actuator restrito a rede interna (documentado em setup-local.md / deploy).

## Resultado esperado
Nenhum segredo no repositório; MIG não pode wipe destrutivo; falta de credencial impede
o start.

## Criterios de aceite
- [ ] Nenhuma credencial hardcoded; tudo via env.
- [ ] Variável de credencial ausente → falha no startup com erro claro.
- [ ] `clean` desabilitado (reforço de MIG-001).
- [ ] Papel de migração documentado como distinto do papel de runtime.

## Dependencias
- MIG-001 (precede)
