# MIG-002 -- Bootstrap migration: enable PostgreSQL extensions (global)

## Contexto
O schema global `journeyos_global` precisa das extensões PostgreSQL antes de qualquer
migração de módulo (notadamente `pgvector` para LEAD/INTL e `pgcrypto`/`uuid-ossp` para
PKs UUID). Esta é a primeira migração versionada (faixa V1, owner MIG).

## Spec de referencia
- SPEC-04 (Data model & migrations)
- contracts/data-model.md §0 (Extensions)
- ADR-004 (multi-tenancy / pgvector central)

## Escopo
- `db/migration/global/V1__mig_enable_extensions.sql` (gerado a partir do bloco `sql`
  `-- schema: global` de data-model.md §0).
- Extensões: `uuid-ossp`, `pgcrypto`, `pg_trgm`, `unaccent`, `vector`.

## Resultado esperado
Ao aplicar, o schema global tem todas as extensões habilitadas (idempotente).

## Criterios de aceite
- [ ] V1 contém `CREATE EXTENSION IF NOT EXISTS` para as 5 extensões.
- [ ] Migração roteada para `db/migration/global/` (schema-aware).
- [ ] Reaplicar é seguro (idempotente via `IF NOT EXISTS`).
- [ ] `/actuator/flyway` lista V1 como applied após a execução.

## Dependencias
- MIG-001 (precede)
