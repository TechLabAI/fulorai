# MIG-004 -- MigrationRunner: global run + per-tenant fan-out

## Contexto
A orquestração central de MIG: aplicar o conjunto global uma vez e, em seguida, iterar
os schemas de tenant aplicando o conjunto `empresa/` a cada um, de forma ordenada e
fail-fast.

## Spec de referencia
- SPEC-04 (Data model & migrations)
- SPEC-05 (idempotency & concurrency)

## Escopo
- `application/service/MigrationRunner` orquestrando: (1) Flyway global; (2) loop sobre
  tenants aplicando Flyway por schema.
- Fail-fast: ao falhar em um schema, abortar e não prosseguir para os demais.
- Logar schema corrente e resultado (ver MIG-008).

## Resultado esperado
Uma execução aplica global + todos os tenants conhecidos, em ordem, ou falha de forma
limpa indicando o ponto de parada.

## Criterios de aceite
- [ ] Global é aplicado antes de qualquer tenant.
- [ ] Cada tenant recebe o conjunto `empresa/` em ordem de versão.
- [ ] Falha em um schema aborta a execução (exit não-zero) sem aplicar os seguintes.
- [ ] Execução sem pendências é no-op.

- MIG-005 (precede — fonte da lista de tenants)
