# GWY-003 -- GatewayErrorHandler (ProblemDetail RFC 7807)

## Contexto
Normalizar todos os erros de borda (401/403/404/429/503/504) como `application/problem+json`,
sempre com `X-Correlation-Id`, conforme a tabela de erros da api-contract.

## Spec de referencia
- SPEC-01-api-surface
- contracts/api-contract.md (§5)

## Escopo
- `api/exception/GatewayErrorHandler` (`ErrorWebExceptionHandler` reativo).
- Mapeamento status → `type` (`/errors/unauthenticated`, `/errors/route-not-found`, etc.).
- Inclusão de `Retry-After` em 429.

## Resultado esperado
Erros de borda consistentes em formato RFC 7807.

## Criterios de aceite
- [ ] Respostas de erro têm `Content-Type: application/problem+json`.
- [ ] Toda resposta de erro inclui `X-Correlation-Id`.
- [ ] 429 inclui `Retry-After`.
- [ ] Sem vazamento de stacktrace/headers internos ao cliente.

## Dependencias
- GWY-001 (precede)
