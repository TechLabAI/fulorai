# GWY-011 -- RateLimitFilter + KeyResolver (Redis)

## Contexto
Rate-limiting distribuído consistente entre réplicas (token bucket no Redis), com chave por
tenant/usuário (autenticado) ou IP (público), respondendo 429 ao exceder (ADR-005).

## Spec de referencia
- SPEC-05-idempotency-concurrency
- adr/ADR-005-rate-limiting

## Escopo
- `RequestRateLimiter` (Spring Cloud Gateway) + `KeyResolver` baseado em `RateLimitKey` (GWY-006).
- Parâmetros `replenishRate`/`burstCapacity` por classe de rota (via `${VAR}`).
- Política de falha do Redis (default fail-open) com métrica/alarme.

## Resultado esperado
Limite agregado entre instâncias; 429 com `Retry-After` ao exceder.

## Criterios de aceite
- [ ] Limite excedido → 429 com `Retry-After`.
- [ ] Chave por `empresaId` (autenticado) e por IP (público).
- [ ] Contador compartilhado no Redis (limite agregado com ≥2 instâncias).
- [ ] Redis indisponível → política de falha configurada aplicada + métrica emitida.

## Dependencias
- GWY-006 (precede)
- INT-GWY-003 (Redis adapter)
