# GWY-010 -- CORS centralizado + security headers

## Contexto
Centralizar CORS no gateway (origens do SPA) e adicionar cabeçalhos de segurança, evitando que
serviços downstream reimplementem CORS.

## Spec de referencia
- SPEC-06-security (§4, §5)

## Escopo
- `infrastructure/config/CorsConfig` (origens de `${GWY_CORS_ALLOWED_ORIGINS}`).
- Tratamento de preflight `OPTIONS` na borda.
- Security headers: `X-Content-Type-Options: nosniff`; `Strict-Transport-Security` (prod).

## Resultado esperado
Política CORS única e cabeçalhos de segurança consistentes.

## Criterios de aceite
- [ ] Preflight `OPTIONS` respondido na borda conforme allowlist de origens.
- [ ] `Origin` fora da allowlist → sem headers CORS de permissão.
- [ ] Respostas incluem `X-Content-Type-Options: nosniff`.
- [ ] Em prod, respostas incluem `Strict-Transport-Security`.
