# GWY-006 -- Domínio de borda + políticas (hexagonal)

## Contexto
Modelar as decisões de borda como domínio puro + políticas de aplicação testáveis fora do
framework (ADR-001), com ports de saída para os adapters (JWKS, Redis).

## Spec de referencia
- SPEC-01-api-surface
- SPEC-06-security
- adr/ADR-001-hexagonal-architecture

## Escopo
- `domain/model`: `JwtClaims`, `TenantContext`, `RateLimitKey`, `RoutePolicy`, `EdgeDecision` (POJOs puros).
- `application/service`: `AuthenticateRequest`, `ResolveTenant`, `RateLimitDecision`.
- `application/port/out`: `JwtVerifierPort`, `TokenKeyProviderPort`, `RateLimiterPort`.
- `infrastructure/config/DomainServiceConfig` (@Bean das políticas POJO).

## Resultado esperado
Políticas de borda unit-testáveis sem subir o gateway.

## Criterios de aceite
- [ ] `domain.*` não importa `org.springframework` nem `jakarta.persistence` (RULE-01/02).
- [ ] Políticas em `application.service` cobertas por testes unitários.
- [ ] Ports `out` definidos; sem implementação no domínio/aplicação.
- [ ] `DomainServiceConfig` registra as políticas como `@Bean`.
- [ ] `./gradlew :services:journey-os-api-gateway:architectureCheck` PASS.
