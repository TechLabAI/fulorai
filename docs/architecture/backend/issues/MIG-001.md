# MIG-001 -- Scaffold base + Flyway configuration

## Contexto
`journey-os-migrations` é o runner centralizado de Flyway. Esta issue cria o esqueleto
hexagonal reduzido (`com.journeyos.mig`) e a configuração base do Flyway que governa
todas as execuções de migração.

## Spec de referencia
- SPEC-01 (API surface — actuator only)
- SPEC-04 (Data model & migrations)
- ADR-001, ADR-002, ADR-005

## Escopo
- Esqueleto Spring Boot gerado pelo scaffold (base package `com.journeyos.mig`).
- `infrastructure/config/FlywayConfig` com: `baselineOnMigrate=true`,
  `validateOnMigrate=true`, `outOfOrder=false`, `cleanDisabled=true`.
- `infrastructure/config/MigrationProperties` (`@ConfigurationProperties`) lendo
  `MIG_DB_*`, `MIG_GLOBAL_SCHEMA`, `MIG_TENANT_SCHEMAS`.
- Actuator: expor `health,info,flyway`.

## Resultado esperado
Serviço compila, `architectureCheck` passa, actuator disponível, Flyway configurado
de forma não-destrutiva.

## Criterios de aceite
- [ ] `./gradlew :journey-os-migrations:compileJava` passa.
- [ ] `./gradlew :journey-os-migrations:architectureCheck` passa (RULE-01..09).
- [ ] `clean` do Flyway está desabilitado (`cleanDisabled=true`).
- [ ] `baselineOnMigrate` e `validateOnMigrate` habilitados.
- [ ] `/actuator/flyway` exposto.
