# GWY-007 -- AuthFilter: validação de JWT (assinatura + claims)

## Contexto
Filtro global que valida o JWT na borda (assinatura via JWKS do WRKS + claims `exp`/`iss`/`aud`/
`empresaId`), rejeitando antes do encaminhamento. Núcleo da segurança de borda (ADR-003).

## Spec de referencia
- SPEC-06-security (§1)
- adr/ADR-003-auth-filter

## Escopo
- `infrastructure/filter/AuthFilter` delegando a `AuthenticateRequest` (GWY-006).
- Uso do `JwtVerifierPort` (adapter JWKS em INT-GWY-002).
- Respostas 401/403 via GatewayErrorHandler.

## Resultado esperado
Rotas não-públicas só passam com JWT válido.

## Criterios de aceite
- [ ] JWT ausente em rota não-pública → 401.
- [ ] Assinatura inválida / `exp` vencido / `iss`/`aud` incorretos → 401.
- [ ] JWT válido sem claim `empresaId` → 403.
- [ ] JWT válido → segue o pipeline.
- [ ] Validação usa chaves do JWKS em cache (sem round-trip por requisição no caminho feliz).

## Dependencias
- GWY-006 (precede)
- INT-GWY-002 (JWKS adapter)
