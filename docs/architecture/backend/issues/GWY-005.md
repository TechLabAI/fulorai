# GWY-005 -- SecurityHeaderStrip (remoção de headers de identidade do cliente)

## Contexto
Anti-spoofing (INV-3): headers de identidade/tenant enviados pelo cliente devem ser removidos na
borda **antes** de qualquer resolução de tenant, para que só o claim do JWT defina `X-Empresa-Id`.

## Spec de referencia
- SPEC-06-security (§2)
- SPEC-01-api-surface (pipeline [2])

## Escopo
- `infrastructure/filter/SecurityHeaderStrip` (`GlobalFilter`, antes do TenantPropagationFilter).
- Remoção de `X-Empresa-Id`, `X-Tenant-Schema`, `X-Principal-Id` de entrada.

## Resultado esperado
Cliente não consegue forjar contexto de tenant/identidade.

## Criterios de aceite
- [ ] `X-Empresa-Id`/`X-Tenant-Schema`/`X-Principal-Id` recebidos do cliente são descartados.
- [ ] Filtro executa antes do TenantPropagationFilter.
- [ ] Teste: requisição com header forjado não chega ao downstream com esse valor.
