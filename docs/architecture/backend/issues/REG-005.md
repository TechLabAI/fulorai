# REG-005 -- Reduced ArchUnit check (RULE-09 base package)

## Contexto
REG does not implement the hexagonal layers, so RULE-01..06/08 are non-applicable (ADR-001).
Only RULE-09 (mandatory base package `com.journeyos.reg`) applies and must be enforced so
the module stays consistent with the monorepo convention.

## Spec de referencia
- ADR-001 (hexagonal applicability for infra module)
- CLAUDE.md — Non-negotiable rules (RULE-09)

## Escopo
- `ArchitectureTest.java` (or equivalent) asserting all classes reside under
  `com.journeyos.reg` (RULE-09).
- Wire `:services:journey-os-service-registry:architectureCheck` to run it.

## Resultado esperado
`./gradlew :services:journey-os-service-registry:architectureCheck` passes and guards the base package.

## Criterios de aceite
- [ ] Test fails if a class is placed outside `com.journeyos.reg`.
- [ ] `architectureCheck` task wired and green.
- [ ] No assertions for layers that do not exist (RULE-01..06/08 omitted by design).
