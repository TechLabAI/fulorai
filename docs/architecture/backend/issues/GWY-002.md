# GWY-002 -- RouteLocator e tabela de rotas (lb://)

## Contexto
Mapear paths versionados (`/api/v1/**`, `/auth/**`, `/webhooks/**`) para os serviços de negócio
via `lb://<service-id>`, conforme a tabela de rotas da SPEC-01. Nenhum host:porta hardcoded.

## Spec de referencia
- SPEC-01-api-surface
- contracts/api-contract.md (§2)

## Escopo
- `infrastructure/config/GatewayRoutesConfig` (RouteLocator programático ou `application.yml`).
- Rotas: wrks-auth, wrks-core, lead, jrny, asst, comm(+webhook), sale(+webhook), intl.
- Predicados por Path; resolução via DiscoveryClient (`lb://`).

## Resultado esperado
Requisições casam predicados e são encaminhadas ao service-id correto; rotas visíveis em
`/actuator/gateway/routes`.

## Criterios de aceite
- [ ] `GET /actuator/gateway/routes` lista todas as rotas da SPEC-01.
- [ ] Requisição a path conhecido é encaminhada ao `lb://`-target correto.
- [ ] Path sem predicado → 404 ProblemDetail.
- [ ] `service-id` sem instância saudável → 503.
- [ ] Zero host:porta hardcoded (apenas `lb://`).
