# REG-004 -- Health probe + structured logging

## Contexto
The orchestrator probes REG via Actuator health; logs must carry the `service` MDC field
for cross-service log correlation (no correlation-id propagation needed — REG initiates
no business requests).

## Spec de referencia
- SPEC-07-observability-health
- platform-patterns.md §4 (logging pattern)

## Escopo
- Enable Actuator health probes (`management.endpoint.health.probes.enabled: true`).
- Logging console pattern including `[%X{service}]`; `com.journeyos` at INFO,
  `com.netflix.eureka` at INFO.

## Resultado esperado
`GET /actuator/health` is a valid liveness/readiness probe; logs are tagged with the service name.

## Criterios de aceite
- [ ] `GET /actuator/health` returns `UP` and is documented as the probe.
- [ ] Liveness/readiness probe groups enabled.
- [ ] Log lines include `[journey-os-service-registry]` via the `service` MDC field.
