# GWY-008 -- TenantPropagationFilter (X-Empresa-Id / X-Principal-Id do claim)

## Contexto
Após a autenticação, derivar o `TenantContext` do claim e injetar `X-Empresa-Id`,
`X-Tenant-Schema` e `X-Principal-Id` no encaminhamento (ADR-004). Origem exclusiva: o JWT.

## Spec de referencia
- SPEC-06-security (§2)
- adr/ADR-004-multitenant-strategy

## Escopo
- `infrastructure/filter/TenantPropagationFilter` delegando a `ResolveTenant` (GWY-006).
- Injeção dos headers de identidade derivados do claim (após SecurityHeaderStrip).

## Resultado esperado
Serviços downstream recebem o tenant resolvido, à prova de spoofing.

## Criterios de aceite
- [ ] `X-Empresa-Id` definido a partir do claim `empresaId`.
- [ ] `X-Principal-Id` definido a partir do claim `sub`.
- [ ] Headers de identidade nunca herdados do cliente (depende de GWY-005).
- [ ] Requisição autenticada chega ao downstream com os headers corretos.

## Dependencias
- GWY-007 (precede)
- GWY-005 (anti-spoofing)
