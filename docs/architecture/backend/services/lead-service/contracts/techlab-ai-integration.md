# TechLab AI Integration — LEAD (capability `qualification`)

> How `lead-service` consumes TechLab AI. **Optional assist** to the Maturity Score with a
> **deterministic fallback** — TechLab AI is never the sole source of a qualification decision.
> Project contract: `docs/architecture/integrations/techlab-ai-integration.md`.

## 1. Capability used

| Capability | Used by | Purpose |
|---|---|---|
| `qualification` | LEAD score recompute | Interpret free-text signals (survey answers, notes) and **suggest** per-dimension contributions to enrich the deterministic score. |

LEAD does **not** use `orchestration`, `document_composition` or `knowledge`.

## 2. Operation (behind `TechLabQualificationPort`)

- Request (conceptual): `{ "leadId", "empresaId", "textos": [ ... ], "dimensoes": ["PERFIL","INTENCAO", ...] }`.
- Response (conceptual): `{ "contribuicoes": [ { "dimensao": "INTENCAO", "delta": 12, "confianca": 0.8, "justificativa": "..." } ] }`.
- Exact request/response shapes come from `integrations/techlab-ai/openapi.json` (**DTOs generated**,
  not hand-written). Endpoint paths are pending the P3 sync (snapshot currently empty).

- `WHERE the qualification assist feature flag is enabled AND free-text signals exist, THE SYSTEM SHALL call TechLab AI and merge its suggested contributions, tagging affected attributes origem=ASSIST_IA.`
- `IF TechLab AI times out, errors, or the circuit breaker is open, THEN THE SYSTEM SHALL compute the score deterministically and set assist_ia=false.`
- `THE SYSTEM SHALL NOT allow an AI-suggested contribution to be the sole cause of a state transition to QUALIFICADO/NAO_QUALIFICADO.`

## 3. Headers / propagation

- Propagate `X-Correlation-Id`, `empresaId`, `principalId` on every call (MDC → headers).
- Service auth per `TECHLAB_AI_JWT_ENABLED`; API key via `TECHLAB_AI_*` env (no secrets hardcoded).

## 4. Resilience (Resilience4j)

| Concern | Value (initial) |
|---|---|
| timeout | 1.5 s |
| retries | ≤ 1 |
| circuit breaker | open on 50% failures / 20-call window; half-open probe |
| fallback | deterministic score (assist_ia=false) — **fail-open** |

## 5. DTO generation & sync

- DTOs at `backend/services/lead-service/src/main/gen/techlabai/dtos/`, generated by
  `openapi-generator-cli` during scaffold from `integrations/techlab-ai/openapi.json`.
- **Never** edit generated DTOs; update via `python scripts/sync-techlab-ai.py --target-sha <sha>`.
- **Status:** blocked — `integrations/techlab-ai/` snapshot is empty (P3, `PENDING_FIRST_COMMIT`).
  Until synced, the assist feature stays behind a disabled flag; the deterministic score is fully
  functional without it.
